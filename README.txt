TALITHAPUT — PERSONAL WEBSITE

Cara membuka:
1. Ekstrak file ZIP.
2. Buka folder talithaput di Visual Studio Code.
3. Buka index.html di browser atau gunakan ekstensi Live Server.
4. Pastikan folder assets tetap berada di lokasi semula.

Struktur:
- index.html
- css/style.css
- js/script.js
- assets/images/profile-home.jpg
- assets/images/profile-about.jpg
- assets/music/background.mp3

Musik tidak otomatis diputar. Pengunjung perlu menekan tombol Play music.
Untuk GitHub Pages, upload seluruh isi folder proyek dengan struktur yang sama.
